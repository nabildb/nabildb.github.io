Furrly

Comunidad web para dueños de mascotas centrada en mascotas perdidas y encontradas: avisos geolocalizados en un mapa, avistamientos que dibujan el recorrido de la mascota y un feed social con publicaciones, likes y comentarios.

  • React
  • TypeScript
  • Tailwind CSS
  • Node + Express
  • Prisma
  • PostgreSQL + PostGIS
  • Supabase
  • Vercel
  • API REST propia con Express y Prisma, desplegada como función serverless en Vercel.
  • Búsqueda de avisos por radio con PostGIS y mapa interactivo con Leaflet y OpenStreetMap.
  • Autenticación con Supabase Auth: la API valida el token JWT contra las claves públicas del proyecto.
  • 34 tests de integración contra PostgreSQL real, ejecutados en GitHub Actions en cada push.
  • Migraciones de base de datos aplicadas automáticamente en cada despliegue de producción.
